# Сплетни Кавалы — памятка

Блог на **Hugo** (тема Bear Blog), хостинг на **GitHub Pages**.
Сайт: https://spletni-kavala.github.io
После любого коммита сайт пересобирается сам за ~30–60 секунд.

---

## 📝 Как добавить сплетню (через сайт GitHub — без программ)

1. Открой репозиторий → папку **`content/gossip/`**.
2. **Add file → Create new file**, назови файл `nazvanie.md` (латиницей).
3. Вставь шапку и текст (шаблон ниже), заполни поля.
4. Внизу — **Commit changes** (это и есть «сохранить/опубликовать»).
5. Через минуту сплетня появится на сайте и в ленте `/gossip/`.

### Шаблон шапки поста
```toml
+++
title = "Заголовок сплетни"                 # → h1 + авто <title>: "Заголовок | Сплетни Кавалы"
slug = "korotkiy-url"                        # адрес: spletni-kavala.github.io/korotkiy-url/
date = "2026-07-25T12:00:00+00:00"           # дата (формат на сайте: «25 июля 2026»)
description = "1–2 предложения, до 160 символов, с ключевыми словами."  # SEO + превью в ленте
tags = ["имя героя", "клуб", "скандал"]
cover = "images/covers/foto.jpg"             # обложка (необязательно)
+++

Текст сплетни в Markdown…
```

---

## 🔍 SEO — что заполнять
- **title** — заголовок. Из него сам собирается `<title>` вкладки (`Заголовок | Сплетни Кавалы`). Бренд дописывать не надо.
- **description** — короткое описание для поиска и соцпревью (OG/Twitter уже подключены). Если не задать — возьмутся первые строки текста.
- **slug** — короткий адрес латиницей (иначе URL будет кириллицей в процентах).
- **tags** — теги/ключевые слова.

---

## 🖼 Обложка
1. Залей картинку в **`static/images/covers/`** (Add file → Upload files → Commit).
2. В шапке пропиши: `cover = "images/covers/имя.jpg"`
3. Обложка появится крупно вверху статьи и на плитке в ленте.
   Без `cover` на плитке будет сиреневая заглушка с ✦.

## ✍️ Форматирование текста (Markdown)
```markdown
## Подзаголовок H2
### Подзаголовок H3
#### H4

**жирный**   *курсив*   ***жирный курсив***
~~зачёркнутый~~   <u>подчёркнутый</u>       (подчёркивание — через HTML)

- список
- пункт
  - вложенный

1. нумерованный
2. пункт

> цитата (например, слова источника)

[текст ссылки](https://адрес.ru)

---                                          (горизонтальный разделитель)
```
Пустая строка = новый абзац. Перенос строки внутри абзаца — два пробела в конце строки.

## 🏞 Картинки внутри текста
```markdown
![подпись](/images/covers/foto.jpg)
```
Размер сам ограничится (не на всю ширину), по центру, со скруглением и тенью.

## 🎬 Видео

**Своё видео (mp4):** залей файл в **`static/videos/`**, потом вставь:
```html
<video controls width="100%">
  <source src="/videos/имя.mp4" type="video/mp4">
</video>
```

**YouTube:**
```html
<iframe src="https://www.youtube.com/embed/КОД_ВИДЕО" allowfullscreen></iframe>
```
`КОД_ВИДЕО` — то, что после `watch?v=` в ссылке. Видео тоже само ограничится по размеру.

## 🕵️ Лица (досье на героев)

Раздел `/people/` — карточки-досье в стиле Интерпола. Каждое лицо — отдельный файл
`content/people/имя.md`. Создаёшь так же: GitHub → `content/people/` → Add file → Create new file → Commit.

### Шаблон досье
```toml
+++
title = "Имя героя"                          # → h1 + авто <title>: "Имя героя | Лица Кавалы"
slug = "imya-latinicej"                       # адрес: /imya-latinicej/
date = "2026-07-25T12:00:00+00:00"            # дата (влияет на порядок и номер дела)
aka = "клички, погоняла"                      # строка «Клички:»
charges = "чем известен / за что прославился" # строка «Известен за:»
description = "SEO-описание, до 160 символов, с ключами."   # для поиска/соцсетей
photo = "images/people/foto.jpg"              # главное фото (mugshot). Без него — тёмный «?»
gallery = [                                   # доп. фото (лента-карусель + просмотр на весь экран)
  "images/people/1.jpg",
  "images/people/2.jpg",
  "images/people/3.jpg"
]
+++

Досье: подробное описание героя…
```

- **title** — имя (h1). `<title>` собирается сам: `Имя | Лица Кавалы`.
- **aka** → «Клички:», **charges** → «Известен за:».
- **photo** — главное фото (mugshot). Клик по нему открывает его **на весь экран**. **gallery** — список доп. фото: листаются стрелками, тоже открываются на весь экран (главное фото идёт первым, дальше — галерея).
- **description** — SEO. Фото заливай в **`static/images/people/`**.
- **Номер дела** присваивается сам: первое заведённое лицо = 000001 (внизу), новые получают следующий номер и встают сверху. Номера не меняются.
- Внизу досье — реакции и комментарии (как у сплетен).

**SEO ленты «Лица»** (страница `/people/`) — в `content/people/_index.md` (title + description).

## 🔧 Разделы и настройки сайта
- **Название/навигация/цвета** — в `hugo.toml` (меню) и `static/magazine.css` (стиль).
- **Описание сайта (главная)** — `content/_index.md` (title + description).
- **Описание ленты** `/gossip/` — `content/gossip/_index.md`.
- **Логотип** — `static/logo.gif`. **Фавикон** — `static/favicon.ico` + `static/images/favicon.png`.

## 📁 Структура
```
content/
  _index.md          — главная (текст «Добро пожаловать» + SEO)
  gossip/
    _index.md        — SEO раздела «Сплетни»
    nazvanie.md      — сами сплетни (посты)
  people/
    _index.md        — SEO раздела «Лица»
    imya.md          — досье на лица
static/
  images/covers/     — обложки постов
  images/people/     — фото лиц (mugshot + галерея)
  images/collage/    — фото коллажа на главной
  videos/            — видео для постов
  magazine.css       — стили
```

## 💻 Локальный запуск (по желанию, если работаешь с компьютера)
```bash
hugo server -D
```
Откроется на http://localhost:1313

## Публикация из терминала (альтернатива веб-интерфейсу)
```bash
git add -A && git commit -m "новая сплетня" && git push
```
Сайт обновится автоматически.
